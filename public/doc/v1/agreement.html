Persetujuan Penggunaan

PERSETUJUAN PENGGUNAAN: Dengan menggunakan Tool ini, Anda menyetujui seluruh ketentuan berikut.

1. FUNGSI TOOL

Tool ini HANYA mengisi otomatis pilihan yang sudah Anda tentukan sebelumnya pada formulir di browser Anda. Tool bekerja secara lokal dan memerlukan klik manual untuk diaktifkan.

2. APA YANG TIDAK DILAKUKAN TOOL

Tool ini TIDAK:

  • Mengirim data ke server manapun
  • Mengakses atau menyimpan data pribadi/pasien
  • Memodifikasi sistem aplikasi
  • Submit formulir secara otomatis

3. TANGGUNG JAWAB PENGGUNA

Anda WAJIB:

  • Memverifikasi ulang seluruh jawaban sebelum submit
  • Bertanggung jawab penuh atas keakuratan data
  • Mematuhi kebijakan aplikasi/website dan ketentuan hukum yang berlaku

4. BATASAN TANGGUNG JAWAB

Pengembang TIDAK bertanggung jawab atas:

  • Kesalahan pengisian data
  • Konsekuensi atau hukum dari penggunaan Tool
  • Gangguan atau error yang mungkin terjadi

5. PRIVASI DAN PERLINDUNGAN DATA

  • Tool ini TIDAK mengakses, mengumpulkan, atau mengirim data ke server eksternal.
  • Tool hanya menyimpan konfigurasi pengisian secara lokal di browser Anda.
  • Data pada formulir aplikasi tetap sepenuhnya di sistem asli.

6. IMPOR & EKSPOR KONFIGURASI

Fitur ini mengelola file konfigurasi pengisian yang dapat berisi informasi pribadi umum.

Jaga kerahasiaan file konfigurasi Anda karena dapat berisi informasi sensitif.

Anda bertanggung jawab penuh atas:

  • Keamanan dan penyimpanan file konfigurasi
  • Memastikan file impor dari sumber tepercaya
  • TIDAK membagikan file ke pihak tidak berwenang

Pengembang tidak bertanggung jawab atas kebocoran atau penyalahgunaan file konfigurasi.
