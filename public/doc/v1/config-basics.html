Dasar

Pengaturan Dandelion tersimpan sebagai JSON lokal di browser Anda — tidak dikirim ke mana pun, dan bisa diekspor atau diimpor sebagai berkas biasa (lihat Lainnya).

Ada dua tempat untuk mengubah pengaturan:

  • Popup ekstensi — pengaturan cepat: profil aktif, URL form skrining, nilai tersemat, URL pemeriksaan, dan register form.
  • Halaman pengaturan lengkap — semua pengaturan per tab, termasuk kata kunci, daftar kecuali, dan pengaturan mode lanjutan.

Setiap pengaturan mengikuti profil aktif — profil adalah unit konfigurasi utuh, sehingga Anda bisa punya beberapa set pengaturan terpisah.
