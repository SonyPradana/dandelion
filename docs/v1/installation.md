# Instalasi

Dandelion adalah ekstensi peramban. Unduh dulu berkas terbaru dari [halaman utama](/) sesuai perambanmu, lalu ikuti langkah di bawah.

> Selalu ambil berkas dari halaman utama — jangan dari sumber lain.

## Desktop

### Brave

1. Unduh paket Dandelion terbaru dari [halaman utama](/) (berkas `.zip`).
2. Buka `brave://extensions` di bilah alamat.
3. Aktifkan **Mode pengembang** (Developer mode) di pojok kanan atas.
4. **Tarik berkas `.zip`** dari folder unduhan dan **lepas di halaman ekstensi** — Dandelion langsung terpasang.
5. Klik ikon puzzle di toolbar, lalu pin **Dandelion** agar mudah diakses.

![Menyeret berkas .zip Dandelion ke halaman ekstensi Brave](/doc/v1/assets/brave-drag-drop.webp)

### Chrome

1. Unduh paket Dandelion terbaru dari [halaman utama](/) (berkas `.zip`).
2. Buka `chrome://extensions` di bilah alamat.
3. Aktifkan **Developer mode** di pojok kanan atas.
4. **Tarik berkas `.zip`** dari folder unduhan dan **lepas di halaman ekstensi**.
5. Pin ikon Dandelion melalui menu ekstensi (puzzle) di toolbar.

![Menyeret berkas .zip Dandelion ke halaman ekstensi Chrome](/doc/v1/assets/chrome-drag-drop.webp)

### Firefox

1. Unduh berkas `.xpi` Dandelion terbaru dari [halaman utama](/).
2. Buka menu Firefox → **Add-ons and themes** (`about:addons`).
3. Klik ikon roda gerigi → **Install Add-on From File…**, lalu pilih berkas `.xpi` yang sudah diunduh.
4. Konfirmasi pemasangan pada dialog yang muncul.
5. Firefox akan memperbarui ekstensi ini secara otomatis — lihat halaman [Pembaruan](/doc/v1/update).

![Menu Install Add-on From File pada Add-ons Manager Firefox](/doc/v1/assets/firefox-install-from-file.webp)

### Edge

1. Unduh paket Dandelion terbaru dari [halaman utama](/) (berkas `.zip`).
2. Buka `edge://extensions` di bilah alamat.
3. Aktifkan **Developer mode** di pojok kiri bawah.
4. **Tarik berkas `.zip`** dari folder unduhan dan **lepas di halaman ekstensi**.
5. Pin Dandelion dari menu ekstensi di toolbar.

![Menyeret berkas .zip Dandelion ke halaman ekstensi Edge](/doc/v1/assets/edge-drag-drop.webp)

## Mobile

### Firefox (Android)

1. Unduh berkas `.xpi` Dandelion terbaru dari [halaman utama](/) menggunakan Firefox di Android.
2. Buka **Pengaturan** Firefox → **Tentang Firefox**.
3. **Ketuk logo Firefox 5 kali** — menu pengaturan tambahan akan muncul.
4. Buka **Pengaturan** → **Install Extension from File**.
5. Pilih berkas `.xpi` yang sudah diunduh, lalu konfirmasi dengan **Add**.

![Menu Tentang Firefox dengan logo Firefox di Firefox Android](/doc/v1/assets/firefox-android-debug-menu.webp)

![Pilihan Install Extension from File pada pengaturan Firefox Android](/doc/v1/assets/firefox-android-install-from-file.webp)

> Hanya berkas `.xpi` bertanda tangan yang dapat dipasang dari berkas — berkas dari halaman ini sudah ditandatangani. Membutuhkan Android 10 atau lebih baru.

## Setelah pemasangan

- Token kuota dibuat dan dikelola melalui [Token Generator](/token-generator.html).
- Masukkan token tersebut pada panel pengaturan Dandelion untuk mulai menggunakan ekstensi.
