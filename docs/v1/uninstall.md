# Uninstalasi

Penghapusan ekstensi berbeda sedikit antar peramban. Token kuota yang kamu kelola di server tidak terpengaruh.

## Desktop

### Brave

1. Buka `brave://extensions`.
2. Temukan kartu **Dandelion**, klik **Remove**.
3. Konfirmasi penghapusan.
4. Hapus berkas `.zip` unduhan jika sudah tidak diperlukan.

### Chrome

1. Buka `chrome://extensions`.
2. Temukan kartu **Dandelion**, klik **Remove**.
3. Konfirmasi penghapusan.
4. Hapus berkas `.zip` unduhan jika sudah tidak diperlukan.

### Firefox

1. Buka `about:addons` → **Add-ons and themes**.
2. Klik tombol **…** pada kartu **Dandelion**, lalu pilih **Remove**.
3. Konfirmasi penghapusan.

### Edge

1. Buka `edge://extensions`.
2. Temukan kartu **Dandelion**, klik **Remove**.
3. Konfirmasi penghapusan.
4. Hapus berkas `.zip` unduhan jika sudah tidak diperlukan.

## Mobile

### Firefox (Android)

1. Buka menu Firefox → **Add-ons**.
2. Pilih **Dandelion** → **Remove**.
3. Konfirmasi penghapusan.

## Catatan

- Uninstalasi hanya mencabut ekstensi dari peramban; token kuota tetap aktif sampai masa berlakunya habis.
- Jika hanya ingin menonaktifkan sementara, gunakan opsi _disable_ pada halaman ekstensi peramban masing-masing.
